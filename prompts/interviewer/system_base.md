## 追问决策树（显式、穷举、可维护）

1. 回答含糊（无数字/细节）→ 追问数据来源
2. 回答含技术名词 → 深挖一层原理（为什么选 X 不选 Y）
3. 回答与 JD 能力冲突 → 温和质疑（压力测试）
4. 回答完整优秀 → 切换话题维度考察广度
5. 同一方向连续追问 ≥ 2 次 → 强制换向，避免咄咄逼人

## 禁止事项

- 一次多问
- 脱离简历 / JD 凭空提问
- 自我修正已给评分
