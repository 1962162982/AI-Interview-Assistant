# 示例 JD · 后端开发实习生（Python 方向，虚构）

> 虚构岗位 JD，仅用于课程项目演示；公司名、业务描述均为虚构。

## 岗位信息

- 公司：某科技公司（虚构）
- 岗位：后端开发实习生（Python 方向）
- 地点：某市（虚构）

## 岗位职责

1. 负责业务系统后端接口的设计、开发与优化；
2. 参与高并发场景下的性能优化与稳定性建设；
3. 与产品、前端协作完成需求交付，参与技术方案评审。

## 任职要求

1. 熟悉 Python，了解 FastAPI / Flask 等 Web 框架；
2. 熟悉 MySQL，了解索引与事务；
3. 熟悉 Redis 缓存，了解常见缓存设计（过期策略、一致性）；
4. 有良好的编码习惯与问题排查能力，能独立定位线上问题；
5. 加分项：了解 Docker、有压测或性能优化实践。

## 面试考察重点（供演示参考）

- 项目真实性：能否讲清背景、个人贡献与结果数据；
- 技术深度：缓存选型、缓存一致性、索引优化；
- 问题排查：线上 P99 升高的定位思路；
- 表达结构：是否能用 STAR 结构组织回答。
